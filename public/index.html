印表機

設定只保存在這台裝置，依帳號與店鋪分開。下載憑證、設定與測試都可從這裡開始，不必先開啟 ESP32 網頁。

首次設定 iPad
  1. 下載憑證

    iPad 請先連到印表機與橋接裝置所在的 Wi-Fi，再下載本店橋接裝置的憑證。已安裝並信任此憑證可跳過前兩步。

    下載印表機憑證

    如果從主畫面 App 無法下載，請在 Safari 開啟本 POS 的「管理 → 印表機」再下載。

  2. 在 iPad 設定中安裝並信任

    ① 設定 → 一般 → VPN 與裝置管理 → 安裝剛下載的描述檔。

    ② 設定 → 一般 → 關於本機 → 憑證信任設定 → 啟用「XIAO Printer Local Root CA」的完整信任。

    這兩項操作需要你在系統設定中完成，網頁無法自動安裝或啟用信任。

  3. 回到本頁完成連線

    在下方勾選「啟用訂單列印」、確認 WSS 位址並輸入裝置存取金鑰，按「儲存並檢查連線」。連線成功後可開啟「中文測試列印」預覽，再按「列印一份」。

此憑證僅適用於本店目前的 XIAO 橋接裝置；其他裝置請使用其管理者提供的憑證。若 Safari 可連線但主畫面 App 失敗，請先在 Safari 操作，並用下方「連線診斷」檢查。

建議使用 xiao-printer.local：同一區網支援 mDNS 時，ESP32 換 IP 仍可透過這個名稱連線。此處是 ESP32 的位址，下方「Xprinter IPv4 位址」才是印表機的位址。

未勾選時金鑰僅保留於目前工作階段；切換帳號、店鋪或登出後須重新輸入。

ESP32 裝置設定

先讀取裝置，再修改設定。以下設定會儲存在 ESP32，影響使用它的所有裝置；需要支援網頁設定的新韌體。

此操作修改 ESP32 的轉送目標，不會變更 Xprinter 本身的網路設定。保存後請再檢查連線。

更換 ESP32 的 Wi-Fi

使用可讓 ESP32 與印表機互通的 2.4 GHz WPA/WPA2 網路。切換時會暫時斷線；30 秒內未取得新網路 IP 就退回原設定。成功後請將 iPad 連到可存取 ESP32 的網路，再重新讀取確認。

密碼只送到 ESP32，不儲存在 POS。新網路連線成功不代表印表機也能連通，仍須檢查 Xprinter 位址。

請先用中文測試單確認可列印寬度與切紙。每次列印一份，不會自動重送。
